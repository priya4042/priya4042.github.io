What it does

A demo e-commerce site for a streetwear brand, built in React with Firebase. It has a hero banner, product pages, a cart and wishlist, sign-in, and an Add Products page for the shop owner. It is a portfolio piece, not a real shop.एक स्ट्रीटवियर ब्रांड की डेमो ई-कॉमर्स साइट, React और Firebase से बनी। इसमें बैनर, प्रोडक्ट पेज, कार्ट और विशलिस्ट, साइन इन, और दुकानदार के लिए प्रोडक्ट जोड़ने का पेज है। यह पोर्टफ़ोलियो का काम है, असली दुकान नहीं।
