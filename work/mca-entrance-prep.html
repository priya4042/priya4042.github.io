MCA Entrance Prep: one app for eleven entrance exams

Building a study app where every answer has been checked twice, every exam has its own pattern, and exam dates update without an app update.

Platform
Android (iPhone build in testing)
Built with
Flutter
Status
Release built, no ads

The problem

Students preparing for MCA entrance exams usually sit several of them - NIMCET, CUET PG, MAH MCA CET and more - each with a different pattern, marking scheme and calendar. Most prep material covers one exam, and coaching is expensive.

What I built

  • Eleven exams, each with its own profile: sections, marks, negative marking, time limits, syllabus, eligibility and colleges.
  • Practice that feels like the real thing: timed mock series in the real format, including section timers that lock like the actual exam.
  • A trick for every question, 48 predicted papers, and real past-year questions.
  • Remembering, not just reading: spaced revision, flashcards, a mistake journal and a study plan that adapts to how close the exam is.
  • Exam dates that stay current. The app reads dates from a small public file, so when a form opens I update one file - no app update needed.

The hard part

A wrong answer key in a study app does real damage. Every answer key was checked by a separate second pass, and automated tests guard each exam's pattern - number of questions, marks and negative marking - so a change can't quietly break it.

Where it is now

The Android release is built. It has no ads, and an iPhone build is being tested.
