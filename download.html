How to install an APK

  1. Tap Download on the app you want. Chrome may say the file can be harmful; tap Download anyway. It is the same app that is coming to Google Play.जो ऐप चाहिए उस पर डाउनलोड दबाएँ। Chrome कह सकता है कि फ़ाइल नुकसानदेह हो सकती है; फिर भी डाउनलोड करें दबाएँ। यह वही ऐप है जो Google Play पर आ रहा है।
  2. Open the downloaded file from the notification or from Files > Downloads.डाउनलोड हुई फ़ाइल नोटिफ़िकेशन से या Files > Downloads से खोलें।
  3. If Android asks, allow Install unknown apps for Chrome or Files, then go back and tap Install.Android पूछे तो Chrome या Files के लिए अनजान ऐप इंस्टॉल करने की अनुमति दें, फिर वापस आकर इंस्टॉल दबाएँ।
  4. Google Play Protect may ask to scan the app. Tap Scan app or Install anyway.Google Play Protect ऐप स्कैन करने को कह सकता है। ऐप स्कैन करें या फिर भी इंस्टॉल करें दबाएँ।
  5. Open the app. You can turn the permission off again in Settings afterwards.ऐप खोलें। बाद में यह अनुमति सेटिंग्स में फिर से बंद कर सकते हैं।

Which file do I need?

The main Download button works on almost every phone sold since 2017. Use the older-phone file only if Android says the app is not compatible.

When the app comes to Google Play

Keep using the copy you have. If Google Play says it cannot update it, uninstall this copy and install it from Google Play. First use the app's Back up my data option, where there is one, so you keep your data.
