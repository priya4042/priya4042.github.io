How it's calculated

Future value = P x ((1+i)n - 1) / i x (1+i), where P is the monthly amount, i is the monthly return (yearly rate / 12 / 100) and n is the number of months. It assumes the same return every month, which real markets never give.भविष्य मूल्य = P x ((1+i)n - 1) / i x (1+i), जहाँ P मासिक रकम, i मासिक रिटर्न (सालाना दर / 12 / 100) और n महीनों की संख्या है। यह हर महीने एक जैसा रिटर्न मानता है, जो असली बाज़ार कभी नहीं देता।
